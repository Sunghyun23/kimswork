Loop Club 0.9.3 — MPC Sample public preview — by kim

MPC Sample firmware 1.3.0.12 only. SD preload mod, not MPC OS VST or firmware.
Actual remote UI and USB audio are tested. Physical controls, calibrated
analog input, power-cycle recovery and maximum-load acceptance are pending.
32 shared Synth/Drum voices, 16 sampler voices. CPU headroom depends on FX.

1. Save your project, power off, and back up existing autorun and projects.
2. Under SampleBoot put the complete folder in autorun/mods/Loop Club/.
   Otherwise put the complete autorun at the card root after preserving the
   old folder. Never merge old/new boot files. Safely eject before booting.
3. Press SAMPLE for LOOP. DATA chooses a track. B1 SOURCE chooses Audio /
   Synth / Drum on an empty track; B2 SOUND edits it. Ordinary pads perform.
4. SHIFT+track pad starts recording with count-in, retaining the LOOP screen.
   SHIFT+same pad or REC finishes at the next bar. SHIFT+another pad queues
   a bar-end handoff. B3 switches REPLACE (new length) / OVERDUB (old length).
5. Audio SOURCE selects INPUT / CHROMATIC / CHOP explicitly. SOUND sets
   Root/Tune/Warp and opens CHOP EDIT. Hold chromatic/chop performance pads
   to repeat; release to stop. INPUT uses SHIFT+SAMPLE: LINE / MIC / USB.
   BROWSE loads an existing WAV into an empty Audio track.
6. Drum SOUND has two editable layers, Tune, Shift, Decay and REV. Ordinary
   BROWSE loads a .lcbank kit; SOURCE pad5 or SHIFT+BROWSE imports a Drum
   XPM after selecting bank A-H. Keep its WAV folders available until saved.
7. SHIFT+B1/B2/B3 selects LOOP / MUTE / CHAIN. SHIFT+LOOP opens loop EDIT:
   B1 COPY, B2 DELETE, B3 MOVE. Source then empty destination for COPY/MOVE;
   same pad twice confirms DELETE. Stop/release notes/held FX before EDIT.
   DATA, LOOP or SAMPLE leaves EDIT. SHIFT -/+ is latest-edit Undo/Redo.
8. FX upper buttons select MIX / TRACK FX / MASTER FX. Effect pads are
   momentary: press enables, release disables. SHIFT+press toggles LATCH.
   Two insert slots can be active together; a third is refused visibly.
   Turn DATA to focus an effect and push for its settings; return with B1.
   Master has texture, performance FX and individual-drum/track sidechain.
9. Stop/release notes before SHIFT+DATA -> PROJECT -> SAVE. Project format7
   includes source PCM/zones, MIDI and independent loop origins/clock for
   relative phase recall. Formats1-6 open; they cannot contain offsets that
   were never saved. Older Loop Club versions cannot read new format7 saves.
   Clip deletion keeps the sound/kit; Undo history clears on load/restart.

Projects: <card>/LoopClub/Projects/. Optional banks: LoopClub/Expansions/.
These folders are never included or replaced by this package. The ZIP only
contains autorun files and licenses; original procedural drums are built in.
It includes no firmware, third-party samples/MIDI, private bank or QA agent.
XPM native FX/filter envelopes/Warp and XPN installers are not supported.
USB is stereo, not independent per-drum stems. GRID shows first64events.
Warp is bounded granular processing, not commercial transient-aware stretch.

Recovery: power off, remove/rename this autorun (or restore its backup), then
power on. Do not remove the SD card during playback/recording/writes. No
firmware flash or internal persistent service change is performed.

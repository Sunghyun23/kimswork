# Looper-first UX direction — 2026-11-22

Owner: “중심은 루퍼여야해.” Larger text alone does not resolve hidden controls. The initial UI splits attention across instrument menus, Shift shortcuts and an undifferentiated16cell grid. Prioritize the selected loop and16track transport states; instruments are track sound sources, not equal top-level products.

Proposal, not installed: top soft keys SOURCE / SOUND / recording mode; selected-loop summary exposes source, count-in/record/play, length/phase and next REC action; compact16track pads emphasize track number/status; dedicated hardware REC/PLAY/STOP remain transport. Use separate source/sound views for subordinate tools. Preserve the existing first-take→set length→repeating recording→finish loop behavior. Per-track pad select/play semantics need explicit review before changes.

# Factory Soul Studies —1.9.0

Native1.9.0 renders of the built-in Dusty Sunday and Velvet Melt timbres at88BPM with Auto Pan1/8. Additional performance settings are saved with these audition states: Cmaj9 / Am9/E / F6/9/D / G9sus4/D,8/6ms Strum, and CHORD GLIDE on with65ms on Velvet Melt. Factory sound selection preserves the user’s chord/performance settings instead of replacing them with this phrase.

Both audio clips are48kHz stereo16-bit WAV, converted directly from native float audio with no external effect or normalization. Values round-trip through native state; verification.json records levels and SHA256s. These are not MPC hardware output recordings. Historical1.8.0 recipe files remain intact in sibling folders.

XPL files are optional audition-state exports, not the factory bank installer. Their browser import is untested and the path targets the known NVMe ARM64 installation. Use factory programs65/66 for reliable timbre selection. Set host tempo manually; a plugin preset cannot set MPC tempo.

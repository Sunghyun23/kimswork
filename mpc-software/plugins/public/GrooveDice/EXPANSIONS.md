# Groove Dice expansions

Groove Dice0.9 uses independent expansion packages. Adding audio does **not** require compiling the engine or merging waveforms into a new sound bank. The plugin reads the registry when a new instance is opened. Close/reopen the instance after changing installed packs; existing instances keep their loaded catalogue and sample references.

This is Groove Dice's own `.gdexp` format and local installer, not automatic registration in the MPC's system Expansion Browser.

## Contents and privacy

- **Original Workshop:**128 original24-bit/44.1kHz mono one-shots,96 kit configurations,2 authored beats and93 timing templates.8roles:Kick/Snare/ClosedHat/OpenHat/Clap/Tom/Cymbal/Perc. Synthesized using oscillator/noise/modal/envelope equations; no source recordings, source MIDI or audio-model output used.96configurations reuse128sounds; they are not96separately recorded drum kits.1606role presets vary sample/part settings and are not1606unique WAVs.
- **Splat Private:** separate optional package containing the existing11039WAV/95MIDI and96reconstructed kits. Marked non-redistributable/private. It is retained locally for the owner and excluded from the public profile. Personal-use packaging does not grant rights beyond the original vendor's terms.
- Base distribution includes Original Workshop only. Future own packs can be installed alongside it. The plugin source is public under mpc-software/plugins/public/GrooveDice. Restricted expansion source and packages stay under expansions/groove-dice/private; a public-safe local artifact does not publish a Release.

## Installed layout

```text
kim - VST - Groove Dice/
  VST/                       same engine for all packs
  Content/
    Banks/
      default.gdbank         original core
      core.manifest.json
      core.id
      core.name
    Expansions/
      registry.tsv           small ID/name/privacy index, generated by installer
      <stable-pack-id>/
        manifest.json
        bank.gdbank          independent payload; not merged with other banks
        RIGHTS.txt
```

One `.gdexp` is a ZIP containing exactly `manifest.json`, `bank.gdbank`, `RIGHTS.txt`. Payload SHA256/size, stable lowercase pack ID, display name, format/version and explicit redistributable classification are recorded. An ID must remain stable across pack updates. Runtime catalogue indices can move; saved samples/MIDI reconnect by SHA and kits/filters reconnect by pack ID plus kit identity.

Installed sound files are not decoded all at once. Runtime indices are merged once outside the render thread; each selected WAV is decoded from its own source bank by the existing bounded64-slot worker cache. Shared voice lifetime remains protected. There is no audio-thread file I/O, allocation or lock added for expansions.

## Player controls

MAIN kit LCD opens an8-row dynamic kit browser. The top `< / >` selects ALL EXPANSIONS or an individual pack; private packs display PRIVATE. KITS, role-sound browser and library share the filter. Kits/pattern files retain source identity; the native MPC PRESET list includes all installed kit programs.

MAIN role Q-Links and DRUMS/KITS Kit Select use normalized catalogue relays, so an added pack does not turn a small knob movement into thousands of indices. ROLL DICE uses the selected expansion filter for whole-kit and mixed-part choices. Existing rhythm rules/locks/recorded fills are retained. CORE8 returns a role to the original core's legacy8variants; it does not select a removed pack.

If a pack is removed, reloading a project marks its missing samples and silences those voices. It does not silently replace them with unrelated core sounds. Reinstalling the same pack restores its stable identities on next reload. A new instance is required after installation/removal; hot deletion while voices are playing is not provided.

## Local installation and removal

From the repository root, target the actual plugin's `Content` directory on a mounted drive or a separate personal assembly. These commands do not connect to the MPC or modify firmware.

```sh
python3 mpc-software/plugins/public/GrooveDice/tools/expansions.py install path/to/new-pack.gdexp --content '/path/to/kim - VST - Groove Dice/Content'
python3 mpc-software/plugins/public/GrooveDice/tools/expansions.py list --content '/path/to/kim - VST - Groove Dice/Content'
python3 mpc-software/plugins/public/GrooveDice/tools/expansions.py remove stable-pack-id --content '/path/to/kim - VST - Groove Dice/Content'
```

Private packages require explicit `--allow-private`. Removing a pack deletes only its installed expansion folder and rebuilds the small registry; core files, engine files, source package and project files remain. Do not remove the bundled core through this command. To update a pack, remove/reinstall the same ID, then reopen the plugin. Make sure source/project backups exist before deleting your only copy of a custom pack.

For network installation use the SDK's official `mpc_remote.py` on an assembled plugin folder. Its current update operation transfers the whole folder, including existing banks; this transfer limitation does not require engine recompilation or merging bank payloads.

## Assembly for sharing versus personal use

The normal build contains only the original core. Optional personal packs are installed in `mpc-software/expansions/groove-dice/private/splat-to-clat/work/personal/Content`, outside the source's `Content` directory.

```sh
python3 mpc-software/plugins/public/GrooveDice/tools/expansions.py assemble --plugin 'mpc-software/plugins/public/GrooveDice/build/kim - VST - Groove Dice' --out '/new/output/kim - VST - Groove Dice' --expansions mpc-software/expansions/groove-dice/private/splat-to-clat/work/personal
```

Default assembly is PUBLIC: non-redistributable packs are excluded, core/payload hashes are verified, and content symlinks are rejected. Add `--personal` only to create the owner's private installation including Splat Private. Existing output folders are never silently overwritten. A manifest is an inventory/classification, not a legal determination of rights in third-party material.

## Creating further packs

`tools/build_original_bank.py` reproducibly synthesizes the initial original pack. `tools/expansions.py pack --bank ... --id ... --name ... --out ...` wraps a compatible GDBANK/GDLIB payload. Add `--private` for restricted material. The pack creator must classify its rights truthfully. The engine reads the new catalogue at startup; no generated C++ sample arrays or per-pack SDK copies are used.

Limits: at most128loaded packs,65535kit programs/role choices and1048575indexed entries. The current compatible payload reader accepts up to512kits and5000role choices per bank. Actual MPC performance and native preset-browser limits may be lower; only the tested two-pack configuration is claimed after device validation. Native programme menus remain host-owned. New342-parameter/identity-trailer states are forward-only;0.8andolder engines do not understand expansion identities.


## 1.0.0 authoring app

Groove Dice Pack Builder is implemented for standalone macOS Apple Silicon and Windows x64. It scans user WAV/MIDI, reviews roles and MIDI mapping, generates/edits/auditions kits, saves projects and exports compatible .gdexp files. Use its Manage Packs to install/remove on a locally accessible MPC drive. Source files are unchanged. Missing roles require explicit silence permission. New manifests declare target groove-dice and plugin_uid KpGy; legacy manifests remain readable. Full native XPN registration and live hot-reload are not provided.

## 1.1 development layers

Layer selection references existing bank entry SHA identities; no .gdexp/GDBANK payload format change or engine-time bank merge is required.

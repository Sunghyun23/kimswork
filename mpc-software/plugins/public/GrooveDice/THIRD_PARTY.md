# Dependencies and content

- MPC Plugin Builder SDK: inmusic-software/mpc-plugin-builder-sdk, pinned to repository mpc-software/third_party/sdk.lock.json (febd2ca5bd9eb16c4a412837196e145566bc981b), MIT. Required notice is shipped in Content/Licenses/MPC-SDK-MIT.txt. SDK was not patched.
- SoundBank.h, groove sequencing/recording, sampler voice logic and skin compiler are project implementation. Build dependencies use the same shared SDK/compiler as Donut Theory.
- HISE HLAC and JUCE are **not linked into Groove Dice**. Prior isolated research conversion tools remain outside this project. They are not part of the runtime package or engine license.
- Historical third-party sample/MIDI records and the optional Splat Private expansion remain in mpc-software/expansions/groove-dice/private/splat-to-clat/, excluded from Git and public profiles. The default Content/Banks/default.gdbank now contains original procedural audio and authored MIDI; the optional private expansion retains its restrictions; installation on a personal device does not establish extraction/derivative-use/redistribution rights. Never include the restricted private bank in a public package. Public profiles contain only the independently created core.
- Artwork generated using the built-in image_gen tool; production prompt/source references are in assets/ and design/. Runtime knob body is generated artwork in assets/bakelite-knob-source-v1.png; native64px frames/ticks/pointer and bevelled button/card materials are compiled by tools/skin_art.py. Background v2 preserves the approved espresso/ivory material direction. Prompts are saved beside source assets. The runtime UI uses native widgets, not a baked concept screenshot.

- Original Workshop generator uses NumPy as an offline build dependency; NumPy is not linked into the MPC runtime. Generated samples come from equations/seeded noise in mpc-software/expansions/groove-dice/public/original-workshop/tools/build.py, not pretrained audio models or source recordings. Core manifest and Content/Licenses/Original-Workshop-Provenance.txt record this distinction.

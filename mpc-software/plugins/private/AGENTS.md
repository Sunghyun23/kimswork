# Private project instructions

루트 AGENTS.md와 docs/repository-policy.md를 함께 적용한다.

- 이 영역은 개인용 로컬 자료다. Git 강제 추가, 공개 저장소 업로드, Pages 노출, GitHub Release 첨부를 하지 않는다.
- 외부 음원은 사용권 확인 없이 새 플러그인의 배포 가능 자산으로 취급하지 않는다.
- `_research/`는 분석 자료다. 정식 프로젝트 스캐폴딩과 구분한다.
- 비공개 프로젝트를 공개로 전환하려면 사용자 지시와 의존 자산 권한 점검이 필요하다.

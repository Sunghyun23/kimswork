# Keyscape reference status — updated0.2.4

User reference is official YouTube Keyscape demos. Direct Keyscape rendering remains prohibited and was never performed. The earlier claim that the available toolchain could not analyze the videos was too broad: web browsing could not play audio, but standard public yt-dlp download + local PCM decoding works. No browser capture or new macOS recording permissions were needed.

Actual audio from Robert Glasper, Shaun Martin, Olivia Belli and Greg Phillinganes official SpectrasonicsVIDEO performances was obtained, decoded and numerically analyzed. Original demo media remains only in private temporary analysis storage. Public source metadata, encoded-file hashes, chapter offsets and proxy-fit evidence are under FeltClub/design/validation-0.2.4. No Keyscape plugin rendering/sample-library access or reference-audio packaging.

Felt Club0.2.4uses accepted Wurli/Upright/Felt pickup/modal voicing coefficients after separate-note validation. Tine/Clav candidates were rejected and remain exactly0.2.3, as do Muted/Thumb. Unknown MIDI/velocity/age/FX, overlapping notes and sparse excerpts limit this to a harmonic-spectrum proxy; do not call it perceptual matching, direct A/B or equivalence. No human/listening-tool judgment is certified.

Workflow tools: tools/calibration/scan_demo_audio.py REFERENCE_DIRECTORY; fit_demo_voicing.py --help; demo_bridge.cpp compiled as an optimized C++17 dynamic library using SDK framework headers; decode_demo_excerpt.swift for normal AAC excerpts, independent ffmpeg only for Opus/WebM. Reference directories must supply private PCM and source metadata; never bundle media. Candidate profiles require >=10%improvement in both training and heldout mean-square feature error. Existing UI/UID/238parameter order/57names retained; no public release/push/site publication. NVMe installation/readback status is in design/validation-0.2.4; MPC app restart remains pending permission to discard Custom chord work.

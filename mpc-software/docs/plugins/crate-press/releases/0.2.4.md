# Crate Press 0.2.4 — public preview

The original Crate Press look, with performance controls grouped together at the bottom.

- **LATCH** and **FULL / LOW / MID / HIGH** curve selection move just above the eight performance buttons.
- All eight original150×82buttons,64px knobs, I/O faders and reference-derived lettering remain. Compact monitor/panel spacing makes room.
- The waveform, curve and meters remain measured/read-only. MPC-owned preset/save/bypass controls remain in the native header.
- DSP, all380parameter identities,32programs, detailed pages and Q-Link assignments are unchanged. No new effects or random generator; Groove Dice stays unchanged.

Native/ARM32/ARM64 and SDK validation pass. Full native/UBSan engine, performance,28effect-pair, bridge and skin tests pass. Host simulator runs at44.1kHz/32and128frames and48kHz/512frames pass. On MPC XL /OS3.10.1.12,128installed runtime files match the build. Remote checks cover track-insert loading, footer curve selection, momentary Tape Stop release, two and all eight latched states, LATCH-off clearing and PERFORM navigation. Hardware audio listening/recording, physical encoders, finger multitouch, worst-case CPU and every routing/latency scenario remain unverified. **This remains a public preview.** External sidechain input is not implemented.

Requires MPC standalone OS3.10.1+ with **Enable Enhancements** and **External Plugin Support** enabled. Place the complete `kim - VST - Crate Press` folder in `VST2 Plugins` on your drive; internal storage is recommended. Preserve work before restarting the app.

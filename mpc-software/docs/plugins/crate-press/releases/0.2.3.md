# Crate Press 0.2.3 — maintenance public preview

Updated package version and installation guidance for the current multi-plugin release. DSP, 32 programs, UI, parameter identities and state format are unchanged from 0.2.2. This is a maintenance release, not a new sound engine or additional effects.

Prefer a single complete installation on internal storage under `VST2 Plugins/kim - VST - Crate Press`. Keep Content, Plugin Skins and VST together. Avoid duplicate old copies across connected drives; save current work before restarting the MPC application.

## Verification and limits

Native/ARM builds, SDK validation, engine/UBSan, host bridge, performance combinations and skin checks are rerun for this package. Earlier actual-device screenshots remain labeled 0.2.2 because the UI is unchanged. This release remains a public preview: full physical Q-Link, multi-touch, track-insert audio and worst-case hardware performance are not certified. External sidechain input is not implemented. Read the manual and bundled verification record.

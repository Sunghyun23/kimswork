# Crate Press 0.2.5 — public preview

Documentation, licensing and distribution patch. DSP, all380parameter identities,32factory programs, native UI/Q-Link maps and eight-effect behavior remain unchanged from0.2.4; native version metadata is205.

- Add explicit project MIT and pinned SDK license notices to source and runtime packages.
- Provide dedicated Open MPC portable ARM32/ARM64 archives alongside the normal SDK ZIP.
- Retain the public-preview status and existing verification limits. No new sound, effect, preset or UI change.

Requires MPC standalone OS3.10.1+ with Enable Enhancements and External Plugin Support. Copy the complete `kim - VST - Crate Press` folder to `VST2 Plugins`, preserve work and restart/rescan. Load as a stereo insert effect on a track or master, not as an instrument. Keep one active copy across drives.

Existing actual MPC0.2.4screens are retained and correctly labeled; they are not new0.2.5hardware certification. Physical encoders/multitouch, hardware audio, worst-case CPU and full device recall are not newly certified. No external sidechain input. No Verified/tested.json claim. In Open MPC this prerelease appears under beta/experimental filtering.

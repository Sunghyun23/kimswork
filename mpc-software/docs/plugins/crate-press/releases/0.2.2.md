# Crate Press 0.2.2 — Public preview

Stereo character compressor and performance effect for MPC standalone tracks and master buses. This first public preview has partial hardware verification.

- Full-band character compression plus independent three-band compression and selective internal bass/tempo ducking.
- Drive, sampler color, wow/flutter, cuts, stereo width and aligned mix.
- Eight combinable performance effects: Tape Stop, Reverse, Repeat, Dub Echo, Filter Dip, Crush, Wobble and Dropout.
- Global LATCH for independent tap toggles; turning it off releases all gates.
- MAIN stereo extrema waveform, static transfer curve and reduction meters.
- 32 factory programs;16 MAIN Q-Links and16 PERFORM Screen controls.
- Lighter lettering, compact section titles, corrected numeric values and visible detail choice captions.

## Install

Unzip crate-press-0.2.2-mpc.zip. Copy the complete kim - VST - Crate Press folder into VST2 Plugins on an MPC drive. Requires MPC OS3.10.1+ with Enhancements and External Plugin Support enabled. Preserve work and restart MPC to rescan; add it as an insert effect under External Plugins.

## Limits

No external sidechain bus; ducking uses internal bass detection or host tempo. Peak Guard is not a true-peak limiter. Transfer graph is static and pre-makeup; waveform is a0.77-second extrema overview. Capture history is at most8seconds. Sound programs preserve performance setup; project load deliberately disarms active effects. Use this preview for evaluation before critical sessions.

# Groove Dice 1.7.0 — perform and capture

Four fills and four momentary snare rolls turn the one-bar generator into a playable performance instrument. LOOP/STOP, fill and roll triggers can be assigned to physical pads without changing MPC Pad Perform settings. PERFORM mirrors the intended Bank B layout, offers selected-slot Screen Q-Link controls and keeps generators away from trigger faces.

Global Roll Dice regenerates the main groove and unlocked performance slots together at the next bar while playing. Slot locks protect favorite phrases; recording/editing a fill locks it automatically. Undo restores all eight sequences. Existing MAIN/kit/role/layer protections and FX are retained.

CAPTURE records actual generated drum events, including fills and rolls, then EXPORT MIDI writes an SMF type0/960PPQ take to Content/Captures. Import it into an MPC track using Groove Dice with automatic playback off. Live plugin MIDI output remains unsupported by the host. Captures are temporary until exported; the limit is32768note-ons and the file uses the starting tempo, not a tempo-change map.

The first782parameter declarations/UID KpGy remain exact;880parameters total. Existing four fill banks and all sound libraries remain compatible. Both Content/Expansions and Content/Captures are protected portable user_data. Public packages contain only the original128sounds/95MIDI assets, never private expansions or user captures. Optional Pack Builder remains a separate1.0.0macOS/Windows download.

## Installation

Preserve Content/Expansions and Content/Captures when copying an SDK folder manually; Open MPC portable packages retain both automatically. Save work and restart/rescan MPC. Device validation targets internal NVMe; SD runtime was not tested.

# Groove Dice 1.6.1

Documentation, licensing and distribution patch; the1.6.0audio engine, UI,782parameters, Q-Link maps and Original Workshop bank are unchanged. Native runtime version metadata is10601.

- Include a detailed Pack Builder guide with macOS Apple Silicon/Windows x64 downloads, folder conventions, kit generation/audition, `.gdexp` export, install/select/remove and stable Pack ID guidance.
- Explain that Pack Builder is an optional separate desktop app. The plugin plays its included core without it. Personal packs and third-party sample libraries are excluded from the public package.
- Add explicit MIT notices for Groove Dice source and the original procedural/independently authored core content. Optional expansions retain their own rights.
- Provide dedicated Open MPC portable ARM32/ARM64 distributions in addition to the normal SDK ZIP.

Requires MPC standalone OS3.10.1+ with Enhancements and External Plugin Support enabled. Copy the complete plugin folder to `VST2 Plugins`, save work and restart/rescan. Keep a single active copy across attached drives. Pack additions require closing/reopening the instrument.

Actual UI captures remain the previous1.6.0device captures and are labeled accordingly; this release does not change the UI. Earlier MPC XL3.10.1.12 remote UI results do not certify this new distribution, physical encoders, hardware audio, all routes or worst-case CPU. No Verified badge/tested.json claim. Current build, host, packaging and catalogue checks are recorded under design/release-1.6.1/.

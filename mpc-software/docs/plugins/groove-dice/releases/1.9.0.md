# Groove Dice 1.9.0

MAIN and PERFORM now have independent Dice and Undo. Build your main groove without losing prepared transitions, then regenerate performance phrases separately.

- MAIN ROLL DICE changes eligible main controls, the basic groove and the selected kit pool. All stored performance slots and master FX remain unchanged, even when a new kit is picked.
- PERFORM ROLL DICE changes only the unlocked twelve snare-roll, fill and hat-roll slots. Fills use the current main groove when generated; later MAIN changes do not replace them. Recorded/edited fills auto-lock. GENERATE explicitly replaces just the selected slot, including a locked slot.
- Independent Undo histories keep MAIN and PERFORM operations from overwriting each other. PERFORM Undo cancels its queued Dice. The fill editor shares PERFORM bulk actions/history, including Undo for local ROLL FILL. ROLL FX remains a separate FX action.
- Bulk Dice applies at the next bar while playing, immediately while stopped. Host count-in, stop and seek cancel queued PERFORM Dice. Random Amount0 preserves musical data.
- PERFORM UNLOCK ALL clears its twelve slot locks. MAIN retains its existing general unlock action. Footer positions, pad assignments, Q-Link targets and finite bar-end phrase timing stay unchanged.
- Show the same dice icon on every ROLL DICE button, including PERFORM and the fill editor.
- Preserve the first917parameter declarations exactly; append only the non-automatable PerformUndo command (918total). Legacy782/880/917states and persistent performance suffixes remain compatible.

Native/ARM32/ARM64, SDK validation, full regression/UBSan and final targeted scope/state/skin tests pass. Final host simulator:19PASS/0WARN/0FAIL. Actual-device verification is recorded with this release; physical encoders, new hardware audio, worst-case CPU and full project recall are not newly certified.

Public packages contain only Original Workshop:128original synthesized one-shots,96kit combinations and95authored/template MIDI assets. Private/commercial expansions and captured takes are excluded. Portable installers preserve both Content/Expansions and Content/Captures. Optional Pack Builder1.0.0for macOS Apple Silicon and Windows x64 creates separate .gdexp packs; see PACK_BUILDER.md.

Requires standalone MPC OS3.10.1+ and Enable Enhancements / External Plugin Support. Restart after installation. Keep one active plugin copy across drives and preserve Expansions/Captures during manual upgrades. Generated MIDI is captured/exported to a file; it is not sent live to the MPC sequencer.

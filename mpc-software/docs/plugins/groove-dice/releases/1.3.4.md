# Groove Dice 1.3.4

A two-page sound editor, per-source reverse and clearer navigation for MPC standalone.

## Changes

- SOUND1/2: Sample / Level / Tune / Shift. SOUND2/2: Start / Decay / Low Cut / High Cut. The same four SCREEN Q-Link groups follow their sound rows on both pages.
- Separate48×48 previous/next arrows surround a visible SOUND1/2 counter. All rows change together; drum/cymbal category changes retain the page. The former selected-sound Detail modal is replaced by this second page.
- Independent REV for all17sources: eight base roles, six additional kick/snare layers and Ride/Crash/Bell. Reverse begins with the next hit/preview; Start trims from the source end, while Decay and Shift remain independent.
- Independent polarity Ø beside every sound name on page2. REV/polarity and user-kit/project state remain separate.
- Fixed dynamic value captions intercepting taps at the center of sample selectors and browser rows. Caption press surfaces preserve a single command per click.
- Includes1.3.3’s visible Dice changes, sixteen padlocks, seven playable RULE styles, live one-bar rhythms, hats/cymbals, source pools, isolated preview and eight-role fill editing.

## Compatibility and package

UID KpGy and the first643 parameter declarations remain unchanged;672 total. Legacy GDLY/GDCY layouts and expansion format are unchanged; a separate GDRV0001 trailer stores reverse settings for eight user kits. Older projects default to forward playback. Newer states cannot be fully represented by older engines.

Public ZIP: Original Workshop only —128 original synthesized one-shots,96 kit combinations, two authored beats and93 timing templates. No personal/commercial expansion payload is included. Actual screenshots show an owner MPC with additional optional packs; their library counts are not the public package’s contents.

MPC standalone OS3.10.1+ with Enable Enhancements / External Plugin Support. Keep one installed copy; internal storage is recommended. Signed Shift reports fixed30ms latency including direct pads. External sidechain and generated MIDI output are not implemented.

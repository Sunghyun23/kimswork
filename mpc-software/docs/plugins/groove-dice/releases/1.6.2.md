# Groove Dice 1.6.2 — expansion-safe catalog upgrades

Fixes the Open MPC distribution's missing user-data declaration. The1.6.1portable packages could remove installed expansion packs during an upgrade; use1.6.2or later for catalog upgrades.

- Both CPU manifests and standard installers declare `Content/Expansions` as persistent user data, preserving pack folders, registry and nested files.
- A dedicated public-only packager always supplies `--user-data Content/Expansions` and checks the resulting manifests/installers before publishing.
- Real generated installer regression tests run in isolated Linux: reproduce1.6.1loss, then verify1.6.2upgrade/reinstall/uninstall retention byte-for-byte for ARM32 and ARM64.
- New actual MPC XL screenshots use only the shipped Original Workshop core:128WAV and95MIDI (2authored beats +93timing templates). The screenshot is pinned in the catalog entry.
- Root README documents project-level MIT scope and exclusions. Pack Builder links/manual remain included.

No DSP, UI,782parameter, Q-Link, preset or core-bank change; native version metadata10602. Host/skin checks and native/ARM/SDK builds pass. Actual remote UI captures do not certify physical encoders, hardware audio, worst-case CPU or every MPC model.

Requires MPC OS3.10.1+ and External Plugin Support. Back up projects/packs before any update. Manual SDK-folder replacement still requires preserving your Content/Expansions folder; it is not the catalog installer. Keep one active installation across drives. Existing Release1.6.1assets are not rewritten.

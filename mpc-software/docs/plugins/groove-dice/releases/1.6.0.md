# Groove Dice 1.6.0

- Nine new triplet hat rhythms: 1/4T, 1/8T and 1/16T, each plain, +FILL or +ROLL. Twenty-four total choices in a three-page left browser.
- MAIN D1 Screen/Program mapping, GROOVE selection, live regeneration, Dice, locks and Undo use the same full range. Straight swing leaves triplet and dotted spacing intact; explicit timing controls remain available.
- Fixed occasional missing hits when sample rounding placed an in-block note exactly at the next block index; main notes, fills and cymbals now keep that hit within the current block.
- Scheduler supports all 24 plain sixteenth-triplet hits per bar and the bounded ending ornaments. Rules, Density and cymbal replacements remain musical constraints.
- First779 parameter declarations and normalized ranges retained; three parameters appended. Old selection and three-bank metadata migrate without rewriting notes. Existing custom host maps to the legacy selector retain its fifteen choices; use Screen or Full Hat Rhythm for all24.
- Global Dice still preserves recorded fills and FX. Kit/pattern/role/layer protection, count-in handling and expansion identities remain intact.
- Dedicated ROLL FILL/ROLL FX buttons clear their transient state after one execution, avoiding stale button state in project round-trips. Invalid packed rhythm codes use a safe fallback.
- Public ZIP: Original Workshop only. Personal/commercial banks are excluded.

See the manual and project VALIDATION.md for automated and actual MPC results and remaining physical-control/audio/CPU limits.

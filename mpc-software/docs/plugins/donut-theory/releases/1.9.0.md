# Donut Theory 1.9.0

Warm synthesis, expanded harmony and independent movement for MPC standalone. This release brings the work since 1.2.3 into one official package.

## What changed

- **66 factory sounds:** Keys / Dusty Sunday and Synth / Velvet Melt append as programs 65/66. Their wide Auto Pan uses 1/8 sync at 70%/80% depth. Set MPC to 88 BPM for the website audition feel. Original 64 program order/names/recipes remain.
- **MAIN:** A=OSC Pair/Mix/Detune/Drift; B=Filter Cutoff/Resonance/Body/Sub; C=LFO1Rate/Depth/LFO2Rate/Depth; D=Drive/Glide/Mod Rate/Depth. Amp and filter ADSRs live on AMP/FILTER detail.
- **Body** adds compensated low-mid density independently of the octave-below sine Sub. The old stored Body field remains inert; the active stage is appended for compatibility.
- **Independent LFO2** adds five shapes and Pitch/Filter/Pulse Width/Amp/OSC Mix targets. Both LFOs have independent Sync, free-rate memory and mode-aware Rate Q-Links.
- **Shared Tremolo/Auto Pan** with five shapes, independent Sync and static Pan. The two motion modes share a module; LFO 1 and 2 remain independent.
- **32 chord types / 96 progression recipes.** Key/Major-Minor reference and circle of fifths, confirmed active-slot transpose, Smooth Voicing with preview/apply, overlapping chord glide and one-shot Strum extend the existing 4–16 slot editor.
- **Actual screenshots and manual:** product detail, Software thumbnail, main-page feature and detailed English manual now describe this release. Two native 88 BPM audio examples are included on the product page.

## Install and update

Requires **MPC standalone OS 3.10.1+**, **Enable Enhancements** and **External Plugin Support** under Preferences → Enhancements (Beta). Unzip `donut-theory-1.9.0-mpc.zip`; copy the complete `kim - VST - Donut Theory` folder into `VST2 Plugins` on your MPC drive. Internal storage is recommended; avoid duplicate installations. Save your work and restart MPC after replacing the folder. The ZIP contains both ARM32/ARM64 binaries and all runtime skin/content files, plus README/INSTALL.txt. The native test library is not a desktop installer.

UID Krql and the first 287 full parameter declarations remain exact. SoundCurrent appends at 287 (total 288), while the original 64-choice alias retains its range. Old state imports seed the new selector; saved custom values remain. Sound selection preserves master Volume, chords/voicings/octaves, reference Key, pad assignments, Strum and CHORD GLIDE preference. New states are not intended for older binaries. Older tracks can cache old Q-Link maps: reset the defaults or compare a fresh instance. Parameter compatibility does not promise identical sound from engines before 1.2.0 or the Body/Sub change in 1.2.3.

## Limits

No new complete physical Q-Link/finger multi-touch certification, worst-case CPU measurement, hardware output recording/listening or full MPC project round-trip certification. Other MPC models/OS versions remain unverified. Sixteen voices are shared; overlapping chord releases can steal voices. Screen chord pads do not send MIDI to MPC; record physical trigger notes instead. The gray host PRESET list remains flat; internal SOUND PRESET is category-first. Optional source audition XPL imports are untested and target a known NVMe ARM64 path; use the built-in sounds for normal selection.

# Donut Theory 1.2.0

A Moog-inspired engine is now the default sound path. This update changes the DSP, not only the factory presets.

## Engine

- New nonlinear oscillator summer, four-stage nonlinear ladder Low-pass and rounded VCA response. The ladder uses trapezoidal integration, a simultaneous nonlinear feedback solve, 2× internal processing and a 17-tap output decimator.
- Resonance responds to level and naturally reduces low-frequency gain. Its maximum is limited below autonomous self-oscillation. The 24 dB/octave slope is asymptotic; the displayed pole frequency gives approximately−12 dB for the cascade at zero resonance.
- Retained the band-limited oscillator wave generators, sub, optional phase modulation, ADSRs, glide and effects. Oscillator phase continues between note retriggers. Band-pass/High-pass/Notch remain 12 dB SVF extensions; final Low-cut remains separate.
- No new mode, engine selector, UI or Q-Link assignment. This is an inspired hybrid engine, not a component-accurate recreation of a named Moog instrument or an official Moog product. 2× ladder processing reduces aliasing; mixer/VCA run at host rate and alias-free behavior is not claimed.

## Factory sounds

All 63 playable Bass/Keys/Synth/Lead/Pad recipes are refitted with revised cutoff, resonance and filter-envelope settings and gentler external Tone/Drive. Output trims are recalibrated from stereo renders. 64 names/program numbers, categories, individual Low-cut settings and the dry Init parameter recipe remain. Init still has Low-cut/effects off but uses the new intrinsic engine path.

## Updating and compatibility

**Existing projects will sound different, even with identical saved controls.** UID Krql and all 208 parameter declarations/order/ranges are unchanged, so settings remain loadable. This does not preserve the old engine's audio. Keep the 1.1.2 package and render tracks before updating when exact recall is required. Sound presets, chords, pad hints, MIDI assignments and Q-Link mappings retain their identities.

Back up your project. Replace the complete `kim - VST - Donut Theory` folder under `VST2 Plugins`, avoid duplicate installations, then restart MPC after saving. Requires MPC standalone OS 3.10.1+, Enable Enhancements and External Plugin Support. The ZIP includes ARM32/ARM64, runtime skins, installation instructions, manual and release notes.

## Verification and limits

- Native/ARM32/ARM64 builds and SDK validators pass with 0 errors/warnings. Engine/UBSan/VST bridge/skin regressions and host simulator 19 checks pass.
- Dedicated analog tests cover four-pole response, resonant emphasis, amplitude dependence, rapid cutoff jumps, 32/44.1/48/96 kHz and reset silence. The coupled solver residual stays below 1e-4 in the tested stress matrix.
- All 64 factory sounds render finite/non-silent offline. Measured test-pattern peak 0.177732–0.288887FS including Init. Sound Trim −1.98..15.21dB. Measurements are not perceived-loudness or all-performance headroom guarantees.
- Identical serialized settings/MIDI were rendered through 1.1.2 and 1.2.0 to isolate engine changes. A 16-voice native benchmark measured about 5.8% average/10.5% worst block in its recorded desktop run. This is substantially more CPU than 1.1.2 and is not a prediction of MPC CPU.
- Existing UI files TUI.json/Q-Links.json are byte-identical to 1.1.2, and screenshots show the actual 1.1.2 MPC Live III / OS 3.10.1.12 interface retained by 1.2.0. No synthetic UI is labelled as a device capture.

The 1.2.0 files were transferred and verified with the official SDK installer on MPC Live III / OS 3.10.1.12. Application restart was blocked pending explicit approval to discard or preserve the current unsaved project, so **the new engine has not been run on hardware**. Hardware audio, CPU/headroom, a full 63-sound listening review, physical-input matrix and a new hardware project round-trip are not certified for this release. Native numerical/audio tests are complete; they do not replace those checks. Screen chords still audition internally rather than recording MIDI into the MPC sequencer.

# Donut Theory 1.12.0

Both envelopes in one place, plus a falling pitch release for keys, bass, leads and chords.

- **ENV** replaces FILTER: Amp ADSR and Filter ADSR sit side by side with editable curves and eight vertical faders. Filter response has its own group for Cutoff, Resonance, Env Amount and Key Track; Filter Type remains a touch list.
- **PLAY** replaces AMP: A Performance, B Chord Play, C Voice/Input, D Release/Pitch Drop. D maps Amp Release / Drop Amount / Drop Time / unassigned.
- PLAY Release and ENV Amp Release are the same parameter; Filter Release is independent. MAIN's filter controls remain unchanged.
- Drop Amount0–24st (0=Off), Time20–2000ms (default250ms). Gate-off snapshots the current pitch and starts a downward semitone ramp. Sustain, legato fallback, equal chord intervals, pending strum cancellation, new voice reset and panic remain safe.
- Try Release400ms, Amount12st, Time250ms. A short Release may end the sound before the drop completes. Drop preferences save with the project and persist across sound selection/ROLL DICE.
- Original artwork, lettering, donut knobs, footer actions and MAIN↔CHORD navigation are retained. No Groove Dice or Crate Press changes.

# Donut Theory 1.1.2

Moog-inspired warmth is now the standard factory voicing. This release also makes chord navigation easier and adds manual physical-pad location hints inside the shared CHORD editor.

## Factory sound update

- Revoiced all 63 playable Bass, Keys, Synth, Lead and Pad presets. Fuller oscillator blends, smoother low-pass shaping, filter envelopes and restrained Tape saturation form the new character. FM, detune, chorus, delay and pitch movement are reduced where appropriate.
- No mode needs to be enabled. Select a factory preset to use its refreshed recipe.
- Retained all 64 preset names and program numbers, individual low-cut settings and the dry Init preset. Init keeps low-cut and effects off.
- Recalibrated Sound Trim using stereo peak measurements. This balances a defined audition, rather than guaranteeing equal perceived loudness in every register or playing style.
- The existing 12 dB state-variable filter remains. This is Moog-inspired preset voicing, not an exact ladder-filter or circuit emulation.

## Chord interface

- Enlarged chord-preset and slot-page arrow touch targets to 44 × 44 pixels; retained the four 222 × 70 chord hold pads.
- Removed repeated HOLD TO PLAY captions. Chord names share the pad face with optional position labels and a small 4 × 4 grid.
- Added PAD LOCATION to the shared CHORD editor: choose a bank A–H and a cell 1–16, then register the actual MIDI input with LEARN. MAIN shows your saved hint; unassigned hints are hidden.
- CLEAR LOCATION removes only the hint, keeping MIDI routing intact. These are manual labels, not automatic detection of physical pad identities or Pad Perform changes.
- Fixed location-cell bindings found during device verification and kept Q-Link bounds hidden in the location drawer, restoring them when it closes.
- Preserved the four synth Q-Link groups and the separate CHORD Root/Type/Voicing/Octave mapping. No per-chord EDIT buttons are added to MAIN.

## Updating

Save and back up your project. Replace the complete `kim - VST - Donut Theory` folder inside your drive's `VST2 Plugins` directory, then restart MPC. Avoid duplicate installations on multiple drives.

The plugin UID and the first 192 parameter IDs/order are unchanged. Sixteen nonautomatable position-hint parameters are appended. Old projects load with hints unassigned. Existing projects retain their saved sound settings; selecting a factory sound loads the revised voicing. Sound and chord presets preserve the manually assigned hints.

## Compatibility and verification

Requires MPC standalone OS **3.10.1 or later**, **Enable Enhancements** and **External Plugin Support**. The ZIP includes ARM32 and ARM64 binaries, runtime skins, installation instructions and a detailed English manual. Desktop DAW installation is not included.

- Native, ARM32 and ARM64 builds and SDK validation: pass, 0 validator errors/warnings.
- Host simulator: 19 checks pass. Engine, UBSan, VST bridge and skin regressions pass, including state migration and position-hint independence from LEARN/sound selection.
- All 64 sounds: finite, non-silent offline renders within the measured test bounds.
- MPC Live III / OS **3.10.1.12**: new-instance MAIN startup, unassigned-hint hiding, A1–A4/H16 location selection, clearing with MIDI preserved, MAIN grid display and Q-Link guide hide/restore checked through Remote Screen Viewer. Website images are actual device captures.

A complete hardware listening review of all revised sounds, new physical LEARN inputs, every physical Q-Link rotation, simultaneous finger multi-touch and a fresh device project save/restart round-trip were not completed for this update. A short remote touch sound and subsequent silence were recorded; this does not certify four long finger holds. Existing engine note-ownership and state tests pass. Other MPC models and worst-case device CPU performance are not certified.

Screen chord pads audition the instrument and do not send MIDI into the MPC sequencer. Physical pad inputs are used for recording. The gray host PRESET list remains flat; use the instrument's SOUND PRESET browser for category-first selection.

# Donut Theory 1.10.0

Generate a whole new sound from MAIN with the new **RND** button.

- Correlated oscillator-to-FX generation covers oscillators, mixer, filter and envelopes, Body/Sub/Drift, modulation and effects within playable bounds.
- **LFO 1, LFO 2 and shared motion Sync turn ON** on each generation, with independently selected musical divisions.
- Chords, Key, pad/MIDI routing, slot settings, Strum, CHORD GLIDE preference and master Volume are preserved. Voice mode and Glide time are part of the generated timbre.
- Both host and internal sound selectors show **Random Sound**. Reselect any factory sound, including the previously selected one, to return to its recipe.
- The approved sixteen Q-Links and all 66 factory programs remain. The first 288 parameter declarations are unchanged; three nonautomatable command/status fields append (291 total). Saved generated sounds restore without rerandomizing.

Native, ARM32 and ARM64 builds and SDK checks pass with no validation errors/warnings. Full regressions include native/UBSan randomization, variable-block audio, chord/pad preservation, state and same-factory reload; host simulator 19 PASS / 0 WARN / 0 FAIL. MPC XL / OS3.10.1.12 internal-NVMe installation was exported back and all124runtime files matched. Actual remote UI captures verify feedback, Sync, names and factory reselection. Complete physical encoder/multitouch coverage, hardware output listening/recording, full project round-trip and worst-case CPU are not newly certified.

Requires MPC standalone OS3.10.1+ with **Enable Enhancements** and **External Plugin Support** enabled. Extract the ZIP and place the complete `kim - VST - Donut Theory` folder in your drive's `VST2 Plugins` folder; internal storage is recommended. Keep important projects and the previous installer before updating.

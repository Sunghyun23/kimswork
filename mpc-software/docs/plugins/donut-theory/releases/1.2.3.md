# Donut Theory 1.2.3 — front-panel SUB

MAIN A is OSC Pair / OSC Mix / Sub / Drift. BODY is replaced by the existing independent sine sub-oscillator, exactly one octave below OSC1. It follows pitch, glide and modulation through the shared filter and amp envelope. Sub 0 is silent; raise it for bass weight without changing OSC Mix. There is no new engine mode or UI theme.

All 64 factory programs migrate their former Body-dependent oscillator mix/sub contribution into explicit OSC Mix and Sub values. The old Body ID remains hidden for parameter/state compatibility but no longer changes audio. Existing user Body automation may therefore sound different. All 208 parameter identities/order and the chord editor remain intact.

## Verification and limits

Native/ARM32/ARM64 builds, SDK validation, engine/UBSan, analog-engine, VST host bridge, host simulator and skin/Q-Link checks pass. Spectral tests verify 110Hz SUB under 220Hz OSC, silence at Sub 0, increased level at 50/100 and no process-time allocation. All 64 migrated factory mix/sub values match their former combined contribution. Installed on MPC XL internal NVMe; dedicated SUB physical rotation/listening was not separately confirmed. Earlier Live III chord/preset checks remain documented with their original version. Screenshots labeled 1.2.2 show the prior BODY label, not a new capture.

Requires MPC standalone OS 3.10.1+ and External Plugin Support. Prefer a single complete internal-storage installation under VST2 Plugins; keep VST, Content and Plugin Skins together. Preserve current work before restarting. Read the included manual and SHA256 checksum.

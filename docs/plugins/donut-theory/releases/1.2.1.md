# Donut Theory 1.2.1

Selection-drawer fix and hardware follow-up for the Moog-inspired engine introduced in 1.2.0.

## Changes

- Fixed chord-bank arrow art and touch surfaces appearing above the left selection drawer. Modal layers stay above ordinary widgets on every tab, with a regression check.
- Replaced website/manual images with actual 1.2.1 MPC captures and updated verification status.
- No DSP, factory recipes, UID, 208 parameter identities/order/ranges or Q-Link mapping changes from 1.2.0.

## Hardware verification — MPC Live III / OS 3.10.1.12

The engine was installed with the official SDK tool, the application restarted with discard authorization, and a fresh instance opened MAIN without an introductory popup.

- All 64 factory programs changed in the expected order and produced sound through a 1.6-second screen chord hold. All 64 recorded gate windows were non-silent; the complete recording peaked at 0.684FS and ended in digital silence. This is a functional audition, not subjective approval of every sound or a category-specific register/loudness comparison.
- Each of four MAIN chord pads held for about 1.8 seconds and released. The recording contains four separate audible regions and a silent final second.
- Cutoff sweeps, resonance up to 100%, all four filter types, filter LFO and independent tremolo were exercised. The filter/load recording had no full-scale samples. This does not prove artifact-free analog output.
- With 5-second releases and overlapping chord triggers, the host CPU display showed 41%; after release it showed 12%. This observed scenario is not an absolute worst-case CPU or sixteen-simultaneous-held-note certification.
- A native plugin preset (.xpl), with Notch / 1.34kHz cutoff / 46.4% resonance / 5000ms release, was saved on 1.2.0 and restored after restart on 1.2.1. A full MPC project round-trip was not performed.
- On 1.2.1, category-first selection, list paging, selection/dismissal, the corrected modal layering, MAIN/CHORD, 4-to-16 slot expansion, bank 13–16, inversions, and all seven plugin pages were visually checked. The final LFO+tremolo hold recording peaked at 0.290FS, had no clipped samples and ended in silence.

Remote Screen Viewer reported cumulative output dropouts during UI/recording tests; the source was not isolated between transport, Mac playback and device DSP. Hardware output is therefore not certified glitch-free. Every physical Q-Link rotation, fresh physical MIDI/LEARN, simultaneous finger multi-touch, other MPC models and full-project restoration were not re-certified. Screen chords audition internally rather than writing MIDI to the MPC sequencer.

Native/ARM32/ARM64 builds and SDK validators pass with 0 errors/warnings. Engine, UBSan, VST bridge, analog and skin regressions plus host simulator 19 checks pass. The earlier all-64 offline render and ladder stress measurements remain applicable because DSP and recipes are unchanged.

## Installation and compatibility

Requires MPC standalone OS 3.10.1+, Enable Enhancements and External Plugin Support. Replace the complete `kim - VST - Donut Theory` folder under `VST2 Plugins`, avoid duplicate installations, then restart MPC after saving your work. ARM32/ARM64, runtime skins, manual, engine notes and release notes are included; verify the accompanying SHA256 file.

**Upgrading from 1.1.2 or earlier changes saved-project sound.** The nonlinear mixer, four-stage ladder low-pass and rounded VCA are an inspired hybrid engine, not an exact Moog instrument recreation. Keep the old package and render tracks when exact old sound is required. The engine is unchanged between 1.2.0 and 1.2.1.

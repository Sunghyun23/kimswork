# Donut Theory 1.2.2

A lighter CHORD editor following reports of stalled MAIN-to-CHORD navigation and unreliable pad-location hints.

- Removed manual PAD LOCATION selectors, A–H bank/cell popups and MAIN position-grid hints. These were visual reminders, not physical MIDI routing.
- Reduced the expanded CHORD widget tree from 10,889 to 1,913. Added a 2,500-widget construction budget regression and cycle detection.
- Kept MIDI Note / LEARN, all sixteen chord slots, saved note assignments, UID Krql, all 208 parameter identities/order and Q-Link maps. The sixteen old location fields remain stored but no longer drive visible UI. No engine or factory recipe change.
- MAIN and CHORD remain two native sub-tabs on the first function key; a repeated press switches between them. Fresh loading opens MAIN with no navigation popup.

## Verification and limits

Native/ARM32/ARM64 builds, SDK validators (0 errors/warnings), host simulator 19 checks, engine/UBSan/bridge/analog/skin regressions pass. A fresh MPC Live III / OS 3.10.1.12 instance opened MAIN and entered CHORD. Repeated remote MAIN/CHORD transitions, inversion selection, 4→8→12→16 expansion and bank 13–16 were exercised. Actual 1.2.2 device screenshots replace the website images.

The original stall’s exact cause was not established through a controlled old/new hardware A/B. Early normal-window remote clicks were affected by coordinate alignment; the valid follow-up used aligned full-screen coordinates. Some rapid-test screenshots lagged behind later confirmed device state, so this is not a transition timing benchmark. Fresh physical Q-Link/LEARN/finger-input matrix and complete MPC project restoration were not repeated. Earlier 1.2.1 engine/audio/CPU observations remain applicable to unchanged DSP; Remote Viewer output dropouts were not isolated and glitch-free hardware output is not certified.

## Installation

Requires MPC standalone OS 3.10.1+, Enable Enhancements and External Plugin Support. Save your work, replace the complete `kim - VST - Donut Theory` folder under `VST2 Plugins`, avoid duplicate copies, then restart MPC. ZIP contains ARM32/ARM64, runtime skins, manual and notes; use the accompanying SHA256 file.

The engine is unchanged from 1.2.0/1.2.1. Upgrading from 1.1.2 or earlier changes saved-project sound; keep the older package and render tracks for exact old-engine recall.
